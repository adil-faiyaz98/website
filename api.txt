info:
  title: SAP Migration Workbench API
  version: 1.0.0
  description: |
    REST API for the SAP Migration Workbench — an enterprise-grade platform that
    migrates integration scenarios from SAP PI/PO, MuleSoft, Dell Boomi, and
    TIBCO BusinessWorks into SAP Integration Suite.

    ## Async model

    Long-running operations (discovery, batch transformation, deployment,
    regression runs) return `202 Accepted` with a `Job` envelope containing a
    `jobId`. Clients poll `GET /jobs/{jobId}` for status and retrieve the
    result via the resource-specific GET endpoint once `status` is `completed`.

    Synchronous operations (single iFlow transformation, validation of a
    pre-generated artifact, comparison) return their result directly with
    `200 OK`.

    ## Error model

    All endpoints return errors using the `Error` schema with an RFC 7807-style
    structure. Validation failures return `400`; missing resources return `404`;
    long-running operations that exceed their timeout return `408`.

    ## Authentication

    All endpoints require OAuth2 Client Credentials. The UI obtains a Bearer
    token from the configured token endpoint and presents it in the
    `Authorization: Bearer <token>` header.
